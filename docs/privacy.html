SKULANE

Privacy Policy

Effective Date: September 17, 2026 · Version 1.0.2
Core Principle: Skulane is an offline-first, local software application. Your store data, orders, customer records, and credentials are stored strictly on your local machine and are never uploaded to any third-party server or analytics service.

1. 100% Local-First Data Storage

All data processed by Skulane resides locally on your computer in an encrypted SQLite database stored in your operating system user profile directory. This includes:

  • Order line items, customer shipping addresses, and transaction amounts
  • Product catalogs, inventory SKU quantities, and barcode mappings
  • Warehouse bin locations, wave picking records, and pack station audit logs
  • Generated PDF waybills, thermal label archives, and customized invoices

2. Hardware & OS-Level Credential Encryption

All private access tokens, API keys, and sensitive merchant secrets are encrypted using the Windows Data Protection API (DPAPI) via Electron SafeStorage before being written to disk. Plaintext credentials are never saved in database tables or unencrypted JSON files.

3. Direct API Connections Only

Skulane only connects outward to external services that you explicitly configure and authorize:

  • Your Shopify Store: Direct bi-directional API connection to sync orders, inventory, and fulfillment states.
  • Your WooCommerce Store: Direct REST API connection to your authorized store domain.
  • Your Courier APIs: Direct REST API communication with configured shipping carriers (e.g., PostEx, Trax, DHL, FedEx, TCS, Leopards, Aramex) for waybill generation and tracking.

4. WhatsApp & Customer Communication

Skulane does not integrate proprietary background bot networks or transmit customer phone numbers to third-party marketing services. When you click to message a customer, the application opens standard https://wa.me/ links in your default system web browser. The user retains complete manual control over sending messages.

5. Zero Telemetry & Zero Analytics

Skulane contains:

  • No tracking cookies or marketing pixels
  • No remote usage telemetry or behavior logging
  • No background crash reporting to developer servers
  • No cloud synchronization of customer data

6. Data Retention & Deletion

You have full ownership and sovereign control over your data at all times. You may completely remove all local data, database records, document archives, and encrypted vault secrets at any time directly through the app by navigating to: Settings → Delete All Data.
